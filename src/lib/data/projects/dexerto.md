Dexerto is a news website specialising in gaming and internet culture. This project set out to redesign the site from the ground up, leveraging the speed and caching capabilities of Next.js. The extisting Wordpress site was turned into a headless CMS, of which GraphQL was used to query the data.

- Modern user interface design.
